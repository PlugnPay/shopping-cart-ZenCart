====================================================
PlugnPay Smart Screens v2 Module (Hosted Payments)
Payment Module for Zen Cart v2.2.x — plugin v1.0.1
====================================================

***** IMPORTANT NOTES *****
This module is provided "AS IS". Limited technical support assistance
will be given to help diagnose/address problems with this module.

This module redirects customers to PlugnPay Smart Screens v2 hosted
billing pages (https://pay1.plugnpay.com/pay/). Your store does not
collect card data onsite.

Transactions are AUTHORIZATION-ONLY (pb_post_auth=no). Orders are
left Pending. Capture, void, and refund are performed in PlugnPay
Merchant Admin — not from Zen Cart.

There is no public demo gateway account. Use merchant-supplied
credentials from your PlugnPay account.
***************************

To Install:

1. Unzip so that the zc_plugins/ folder merges into your Zen Cart root:
     zc_plugins/PlugnPaySs2/v1.0.1/...

2. In Admin → Plugins (Plugin Manager), install/enable
   "PlugnPay Smart Screens v2".

3. In Admin → Modules → Payment, install "PlugnPay Smart Screens v2"
   and enter your Gateway Account.

4. Configure currency, zone, database storage, and debug logging
   as needed.

5. Place a test order using your merchant account / PlugnPay test
   procedures.

See README.md inside this package for full documentation,
configuration reference, troubleshooting, and a manual test checklist.
